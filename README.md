# 不止日常 (Beyond Daily) · 治愈系萌宠探索与日常打卡微信小程序

基于设计原图完整还原、深度整合的微信小程序项目。包含日常自律打卡、温馨小屋场景、个人档案中心、萌宠大自然乐园与贴纸图鉴四大核心体验。

---

## 快速导入与运行

1. 打开 **微信开发者工具**
2. 点击 **导入项目**
3. 选择目录：`d:\habbit`
4. AppID 选择 **测试号**（或填入你自己的 AppID）
5. 开发模式选择 **小程序**，点击 **确定导入**
6. 开发者工具即可自动完成编译并展示完整交互界面！

## 项目页面与特色功能架构

### 1. 探索页（主页 · `pages/explore/explore`）
*对应设计图：《萌宠探索日常任务界面.png》*
- **自然艺术顶栏**：集成“不止日常”书法徽标、草地暖阳与探头猫咪艺术原图。
- **地球Online 冒险卡片**：
  - 显示等级 `Lv.3 生活探索家`、经验进度条 `240/500` 与闪烁冒险徽记。
  - **每日奖励**：点击礼盒领取连续打卡奖励（获得经验值与小星星，记录连签天数）。
- **每日任务体系**：
  - 📷 **记录生活**（拍一张今天的生活瞬间）：点击拍照/相册上传，写下日常心情旁白，保存到相册并打卡成功。
  - 📝 **整理空间**（整理一个小角落）：支持快速完成/恢复，完成奖励 +10 经验值，+5 小星星。
  - 📖 **阅读计划**（读书或听书15分钟）：内置专注阅读计时弹窗与打卡确认。
  - ➕ **自定义挑战**：支持用户自主创建今日新习惯。
- **本周挑战（连续3天早睡）**：
  - 梦幻星空睡眠小狗原图底卡，3天打卡进度圆点，一键早睡打卡。
- **今日幸运事件**：
  - 幸运四叶草与猫爪印章，点击可抽取每日治愈签文（大吉、上吉等随机灵感语录）。
- **我的成长与鼓励小狗**：
  - 展示小星星、等级、成就数、收藏数；点击右下角萌宠小狗触发鼓励对话与亲密互动。

### 2. 我的（双模态一键切换 · `pages/mine/mine`）
*对应设计图：《暖心日常个人主页 UI.png》与《2b8e2c52-2683-4b3d-bfc2-b33874ad4e75.png》*
顶栏提供 `[ 🏡 温馨小屋 ]` 与 `[ 👤 个人档案 ]` 随心双向无缝切换：

#### 模态 A：温馨小屋场景态（默认）
- **顶部用户卡**：戴帽女孩苗苗真实头像、生活签名、等级进度、晴天天气与云梦坐标。
- **数据小统计**：成就、勋章、收集三联卡。
- **温馨房间场景交互**：
  - 房间全景画卷（书架、窗景、吉他、床铺与地毯）。
  - **角色互动气泡**：轻触苗苗触发温情问候语录（“今天也要开心呀～ ❤️”）。
  - **地毯猫咪交互**：轻触橘猫触发呼噜噜打盹反馈与浮动爱心动画。
  - **浮动功能入口**：
    - `👕 装扮 >`：打开衣橱弹窗，查看已穿戴的渔夫帽、工装外套、工装裤、登山鞋与双肩包。
    - `🐾 陪伴宠物`：打开萌宠选择器，切换当前陪伴的小动物。
- **我的工具箱（6大实用模块）**：
  - 📷 **相机**：快速打卡
  - 🖼️ **相册**：生活回忆画廊，可查看已记录的照片与生活感悟
  - 📒 **记事本**：治愈便签日记，支持新建与删除
  - 📅 **日历**：按月打卡日历，标注重阳爪印印章与连签天数
  - 🧭 **专注**：15分钟治愈番茄钟，支持倒计时、暂停与完成打卡
  - 💬 **更多**：设置、数据重置与功能菜单
- **我的成就墙**：
  - 完整展示《初来乍到》、《记录生活》、《阅读达人》、《探索者》、《森林挚友》5枚精美徽章，轻触可查看达成条件与奖励。

#### 模态 B：个人档案列表态
- 经验值（56）、小星星（12）、成就数（3）、称号（生活探索家 >）四维指标看板。
- **我的装扮卡片**：帽子、外套、裤子、鞋子、双肩包槽位，配合 Q版苗苗立绘展示。
- **我的宠物卡片**：已领养宠物与待解锁宠物的槽位展示，配以草地猫咪插画。
- **功能菜单列表**：个人信息编辑、我的消息中心（红点提示）、兑换记录、意见反馈、关于我们。
- **底部长幅插画**：“在不止日常，发现生活的更多可能～”木牌风景画。

  - 浮动展示拥有的星星数量与当前陪伴宠物的心声气泡。
- **萌宠交互控制台**：
  - 支持在 **橘宝（橘猫）**、**旺仔（小狗）**、**团子（灰猫）** 之间自由切换。

- **萌宠贴纸与爪印图鉴**：
  - 完整收录原图底部的 6 枚专属素材：
    1. 橘宝头像贴纸
    2. 团子头像贴纸
    3. 旺仔头像贴纸
    4. 暖粉肉垫印章
    5. 曜黑肉垫印章
    6. 暖咖肉垫印章
  - 每一个贴纸均可点击查看详细图鉴故事，用于生活日记打卡！

## 体验亮点

- **像素级原图还原**：所有图标、插画、卡片风格、色彩层次均严格遵循原图。
- **丰富趣味的微动效**：包括气泡轻浮动（`floatAnim`）、爱心升腾（`heartFloat`）、按钮回弹反馈等。
- **真实闭环的状态经济系统**：每日任务打卡获得小星星与经验值 → 经验值提升生活探索家等级 → 小星星用于在萌宠乐园投喂毛茸茸伙伴 → 解锁图鉴与成就，形成有爱自洽的正向治愈闭环。
